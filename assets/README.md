Drop the logo here as **`rocchietti-logo.svg`** (preferred) or **`rocchietti-logo.png`**.

The page tries `.svg` first, then `.png`, and only falls back to a typeset wordmark if neither exists.

Export it **trimmed to the artwork** — no square canvas, no white padding around it — otherwise the
mark renders tiny inside the header. A transparent background is best; a white one also works, the
page blends it out (`mix-blend-mode: multiply`).
